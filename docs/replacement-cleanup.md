# Cleanup after replacement

After a verified replacement, the app removes eligible generated work files from
that completed job. It does not delete the new library file, job history, active
work or safe-copy outputs that you still need to review.

If you chose **Create smaller copies**, the original and the new copy both take
space. To reclaim library space, use **Replace original with this copy** when the
result offers it, or choose replacement for a future run.

Do not delete the entire output folder: history and recovery records live there.
Storage snapshots can retain deleted data, so the server's free-space reading may
not increase by exactly the savings shown in the app.
