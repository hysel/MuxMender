# Run your first conversion

Start with a few videos, not your whole library.

1. Open **Add videos** and select a folder or an individual video. Folder
   selection includes subfolders by default; choose one level if you don't want that.
2. Choose **Create smaller copies**. Your originals stay where they are.
3. Leave encoding on **Automatic**, resolution on **Original resolution**, and
   quality on **Balanced** for a straightforward starting point.
4. Select only output codecs your players can use. HEVC and AV1 support varies
   by device, even when your media server can transcode them.
5. Review the preview, including the selected files and savings requirement.
6. Add the selection to the queue and follow it in **Overview**.
7. Read **Results** when it finishes. If a full copy passed, compare it with the
   original on your usual player before deciding what to keep.

## Choose the action you actually want

| Action | What you get |
| --- | --- |
| Inspect | File information and a processing plan. No conversion. |
| Test samples | Short comparisons of quality and estimated size. No full video. |
| Create smaller copies | A full, checked output if it qualifies. Original kept. |
| Convert and replace | A checked replacement. Original removed only after verified publication. |
| Keep originals | A recorded decision not to convert those files. |

**Inspection complete** isn't a converted video. Submit a new request with a
full-conversion action if you want a smaller file.

## Replace an approved copy without encoding again

For an eligible full safe copy, Results offers **Replace original with this copy**.
The confirmation shows the files and sizes. Approval queues another verification
and replacement; it doesn't repeat the encoding.

If either file changed or disappeared, the app won't blindly approve it.
Read-only media and unresolved recovery work can also prevent replacement.
Dismiss the confirmation to keep both files.
