# What you can do in the app

- Select one video or a folder, including subfolders.
- Inspect files, test short clips, create smaller copies or replace originals.
- Use automatic encoding selection or choose available output options.
- Choose quality, savings and resolution preferences.
- Follow current work, pause new starts, cancel jobs and review results.
- Filter results, retry eligible files and approve eligible copies for replacement.

Replacement removes the original only after the new file passes validation and
is verified at its destination. Keep backups for anything you cannot replace.

A folder selection is a request, not continuous folder watching. Some files will
be kept because conversion would not save enough space or meet your quality
settings. A processing error is shown separately from an intentional keep decision.

Use the browser UI after installing the published image. Available controls may
differ with the installed version; check the release notes before updating.
