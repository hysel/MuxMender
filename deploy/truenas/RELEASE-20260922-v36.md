# MuxMender 20260922-v36

## Changes since v35

- Minimum savings defaults to 25%; the dashboard offers 25%, 20%, 15% and 10%.
  Quality floors are unchanged. Existing queued jobs keep their saved settings.
- Automatic removal of disposable generated media and bulky validation evidence
  after rejected/failed work, with original-source and recovery protection.
  Replacement cleanup now handles internally shared intermediates and more raw
  evidence. Compact summaries, receipts, errors and history remain.
- Staged source preflight: metadata, AAC priming, full audio decoding and copied
  track reading. Source packet evidence is reused only within the same workflow
  after fresh source/evidence checksums. No extra mandatory full video decode.
- Preserve supported MP4 AAC priming using Matroska CodecDelay and copied audio.
  Full decoded audio proof is required; timing tolerances are not widened.
- Long HDR frame checks may use four CPU threads when bounded shared-host
  headroom permits; otherwise two. Full metadata evidence remains enabled.
  The local sample benchmark was about 37% faster; TrueNAS speedup is unmeasured.
- Validation-reader ETA and correct HDR frame-validation timing categorization.
- Dashboard totals distinguish conversion, no-benefit, error and other outcomes,
  without double-counting retries of the same video.
- Release-context dependency coverage fixes and new regression tests.

## Deployment

Image tag: `muxmender-app:20260922-v36`.
Use the staged build context; keep the existing mounts, user IDs, GPU assignment
and app settings. Do not restart while conversions/publication are running if
you want them to finish. Keep the queue paused for the update and verify the
displayed version afterward. Installing this version does not itself grant
replacement permission, change saved job settings or resume a paused queue.

Choose the desired savings threshold when submitting new jobs. Pending v35 jobs
saved with 0% do not silently become 25% jobs. Do not edit requests.json while
the service is running.

No driver upgrade is required by this release. Faster NVENC preset benchmarking
is queued research, not a changed production preset in this version. Dolby
Vision automatic routing is unchanged.
