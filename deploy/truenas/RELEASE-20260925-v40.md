# MuxMender 20260925-v40

This release keeps changing HDR brightness information intact and makes results
and disk usage easier to understand.

- Shared HEVC preservation restores per-frame content-light values without
  changing encoded picture data. A full NVIDIA HDR10+ test passed the configured
  validation checks and produced a 34.71% smaller separate copy. This is evidence
  for that tested path, not a promise of savings on every source.
- Automatic terminal cleanup removes disposable streams and validation exports
  after success, rejection, errors and graceful cancellation. Final deliverables,
  selected review samples, source files and recovery evidence remain protected.
  Forced termination can still leave files needing guarded recovery review.
- Activity reports separate replacements, review copies, no-benefit outcomes,
  processing errors and other results, with CSV export and attempt history.
- Source file sizes appear for queued/running videos and results. Output sizes
  appear when available. Retained copies are not counted as reclaimed space.
- Includes the pending validation diagnostics, decoded-clock recovery checks,
  source-driven codec search and result-reader parity fixes. Missing-timestamp
  recovery still requires independent payload/decoded-audio proof.

Quality and source-replacement validation thresholds have not been relaxed.
The separate damaged-AC3 repair experiment is NOT an automatic production repair;
the app continues to retain damaged sources rather than silently discard audio.
