# MuxMender 20261001-v47

## Less repeated work, unchanged quality checks

This release includes the v46 improvements plus:

- Reuse complete strict audio checks within a job when both files remain unchanged.
- Stop a quality-limited trial earlier when its measured scene fails quality.
  Every required scene must still pass before approving a conversion.
- Give short GPU trials bounded priority, with aging to protect longer waits.
- Reuse private authenticated source-audio evidence on retries, tied to the full
  source checksum, decoder and validation code. Output validation is never cached.
  Records expire after 30 days and are limited to 2,048 small records.
- Include the persistent GPU monitor installer and TrueNAS reboot registration.
  It updates the existing monitor service rather than installing another collector.
- Cancel jobs now includes active processing, pauses the queue and cancels waiting
  jobs after confirmation. Shutdown remains visible until workers exit. An active
  replacement transaction finishes safely rather than risking partial publication.

Quality, timing, metadata and savings requirements are unchanged. Source files
are replaced only through the existing explicitly selected replacement workflow.
The standalone script and app use the same processing engine.

## What we tested

The isolated RTX 5050 image passed 145 regression tests and 65 post-fix tests.
All 16 five-second HEVC/AV1 preset trials passed preservation and quality checks.
Changing presets did not give a meaningful speed gain on this short fixture,
so production presets are unchanged. Paired frame readers produced identical
evidence but were slower; that experimental option stays disabled.

These tests do not establish a new whole-library speedup or new HDR qualification.
Generated media and work files were cleaned, while reports were retained.

## Deploy after the current run finishes

Build tag: `muxmender-app:20261001-v47`.
Run the staged build script only after active processing finishes. It builds and
smoke-tests an isolated image; it does not switch the app image or resume a queue.
After the checks pass, select this image in TrueNAS and preserve your media/output
mounts, GPU assignment, UID/GID, port and saved settings.

For the bundled host-monitor update, run the prepared installer as root with
`--install --group` set to the app's existing group ID. Change its read-only
Host Path to `/var/lib/muxmender-gpu-monitor`, retaining container path
`/gpu-telemetry` and `MUXMENDER_GPU_TELEMETRY=/gpu-telemetry/activity.json`.
The installer updates the existing service and reuses a matching reboot task;
do not launch a second collector. See [GPU sharing setup](../../docs/gpu-monitor-setup.md).

Do not clear the output folder: it holds queue state, history and replacement
receipts. Existing queued requests retain their saved options and budgets.
