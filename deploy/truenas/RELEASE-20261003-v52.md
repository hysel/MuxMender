# MuxMender 20261003-v52

## Faster HDR inspection

This release includes the qualified GPU frame reader in the app image. The
shared processing engine automatically uses it for covered AV1 and HEVC HDR10,
PQ and HEVC HDR10+ inputs on the qualified RTX 5050 and driver 580.173.02.
Other hardware, drivers and unqualified formats continue with CPU inspection.
No new environment variable or dashboard setting is needed.

Complete real-file comparisons measured 78.67% less inspection time for AV1,
88.64% for static-HDR HEVC and 94.86% for HEVC HDR10+. Every frame's timing,
geometry, color and HDR metadata matched. Deliberately damaged inputs were
rejected. These numbers describe inspection, not total conversion time.

The isolated image test passed the image-owned loader, shared source/output
dispatch, complete frame validation, quality, source integrity and savings
checks. Its generated output was 37.65% smaller. Temporary files were removed
before completion. All 65 Linux reader regression tests passed.

GPU admission and sharing, pause/cancellation, corruption checks and all quality,
metadata and verified-replacement requirements remain in place. Docker device
requests that expose the qualified GPU while reporting a `void` selector are
supported after exact sole-device and driver verification.

## Included fixes

All v51 changes and the pending shared copied-audio mux recovery are included.
The recovery preserves original audio clocks and uses ordinary full validation;
it does not change timestamps or waive preservation checks. Reader completion
is recorded only after temporary cleanup and report persistence succeed.

Image: `muxmender-app:20261003-v52`.

Run the staged build script, then change the app image tag after its smoke
checks pass. Keep existing mounts, GPU assignment, UID/GID, port and monitor
settings. Refresh the dashboard and resume the queue when ready.
