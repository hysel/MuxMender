# Folder-first UI

Select folder opens a folder-only browser. Navigate into a directory or enter
its server path, then choose Use this folder. The picker closes and that folder
becomes the workspace. Work on all directly contained videos or one video from
the dropdown. Change folder explicitly switches the workspace.

Only target and action are exposed initially. Encoding options, job queue/logs,
and app configuration are collapsed by default. Include subfolders is an
advanced option for whole-folder work and is disabled for individual videos.
Folder changes invalidate any earlier preview. Selection alone starts no work.
The server's existing source protection and exact-preview confirmation remain.

Build the staged image:

```sh
sudo docker build -f /mnt/FR4G/Apps/muxmender/app-build-20260918-v6/deploy/truenas/Dockerfile.app \
  -t muxmender-app:20260918-v6 /mnt/FR4G/Apps/muxmender/app-build-20260918-v6
```

Change only the existing app's image tag to `20260918-v6` and refresh the browser.
Keep v5 settings: controls enabled, old autonomous queue disabled, source env
blank, media read-only, original GPU/authentication/mount settings unchanged.
Wait for any active jobs to finish before restarting the app.
