# MuxMender 20260929-v43

This build integrates the approved workspace direction into the real app,
instead of shipping the separate mockup or its sample data.

- **Overview:** current work, queue controls and resource settings.
- **Add videos:** a dedicated setup view, preserving folder/file selection,
  recursive scope, age filters, conversion options and replacement confirmation.
- **Results:** outcomes and history, with search/sort and activity reports
  collapsed until needed. Dates, sizes, reasons and report exports remain.
- Lifetime confirmed savings and CPU/GPU/RAM readings stay above the views.
- Successful queue submission returns to Overview. Returning to setup preserves
  selection. Hash links and browser navigation select the corresponding view.
- Calmer light/dark styling, keyboard focus, semantic links and disclosures,
  responsive spacing and reduced-motion support.

This is a functional adaptation of the mockup, not a literal copy of its demo
wizard or fake data. Bulk queue clearing is not included. The same backend and
publication safeguards remain; this release does not change conversion policy.
The GPU sharing feature and reliability fixes from v42 are retained.

## Checks and limits

Structural accessibility, contrast and DOM-model navigation tests are included.
A visual browser/assistive-technology review was not available in this session;
these tests are not a claim of Section 508 certification. A local read-only
preview was prepared before packaging.

Build and select `muxmender-app:20260929-v43` in the existing TrueNAS app. Keep
the existing mounts, ports, GPU assignment and UID/GID. Retain v42's read-only
telemetry mount and `MUXMENDER_GPU_TELEMETRY` variable. Deploy with the queue
paused, verify the new navigation and version, then resume separately.
This archive is a Docker build context, not an already-built image.
