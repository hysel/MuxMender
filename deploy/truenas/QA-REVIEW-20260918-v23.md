# v23 — QA and architecture review

Includes v22 workspace/history/recovery work and v21 efficiency screening.
Review scope: measured media validation, queue admission/completion, publication
guardrails, durable records, recovery UI and release packaging. This is a targeted
code review with regression tests, not a claim that the entire project is bug-free.

## Confirmed findings fixed

1. **False language metadata failure:** `LANGUAGE=eng` and `language=eng` were
   treated differently. Normalize tag names only, including chapter tag names.
   Preserve strict value comparison; conflicting aliases fail closed. Errors now
   name the stream, tag and before/after values. Regression includes all six
   audio/subtitle language values observed in Language case B.
2. **Nonfinite duration bypass:** NaN could pass a difference comparison. Both
   durations must now be finite and positive; the original timing tolerance stays.
3. **Pending jobs stuck after preflight errors:** claim the request for exception
   accounting before source checks. Missing/changed-source failures receive a
   terminal state, timestamp and failure count; no encoding is launched.
4. **Lost failure explanation:** copy a worker's recorded error into the request
   instead of replacing it with a generic worker.log message.
5. **Incomplete success records:** missing/empty/out-of-scope outputs or missing
   source/hash evidence no longer become ready copies. Publication still performs
   independent content hashes and all existing safety checks.
6. **Publication argument validation:** reject nonfinite/out-of-range savings,
   invalid job identifiers and empty files before publication.
7. **Durability:** queue/publication JSON uses exclusive, unique temporary files,
   file synchronization, atomic rename and POSIX directory synchronization.
8. **Unowned state changes:** resource-profile writes require a ready control
   worker, consistent with archive/recovery control ownership checks.
9. **Unreadable dashboard root:** skip inaccessible artifact roots rather than
   disconnecting the entire dashboard on PermissionError.
10. **Recovery UI races:** discard stale log/retry/cleanup-preview responses when
    a card changes to a newer attempt. Display orphan recovery paths. Interrupted
    publication wording no longer promises the source pathname is untouched.
11. **Portable Docker context:** release builder assigns directories 0755/files
    0644, excludes caches/package metadata and refuses overwriting an archive.

No quality thresholds were lowered. No source media, active queue or production
container is changed by staging. Language case B's existing copy has NOT received
full revalidation or replacement approval from this code review; fixing its tag
comparison does not imply that later checks have passed.
