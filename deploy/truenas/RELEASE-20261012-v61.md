# v61 — Faster qualified frame checks

Exact image qualification and public registry download checks passed. Published
as `ghcr.io/hysel/muxmender:20261012-v61`; not deployed by the release process.

The tested image is
`sha256:a2cd06a2d83e3a32ed0557edcb3b787cde832c4d8e0dc4e360df69ed848c255c`.
Its runtime suite passed 227 tests with nine skips. Generated NVIDIA checks and
the actual host-receipt loader passed using packaged application code only.
The final generated workflow took 64.91 seconds with CPU readers and 58.03
seconds with GPU readers (10.59% less). All 1,464 frame records matched, quality
scores were identical and temporary media cleanup removed 146,546,042 bytes.

## What changes

- AV1 8-bit SDR Matroska files can use the qualified GPU frame reader. Full-file
  evidence on the tested RTX 5050 reduced one frame scan from 27 minutes to
  2 minutes 55 seconds, with every requested frame field matching exactly.
- A private, root-owned qualification receipt can persist across image updates.
  It must match the reader binary, GPU, driver and tested format. Missing or
  mismatched evidence keeps complete CPU validation; it does not reject the video.
- GPU sharing saves directly from its toggle, with saving and error feedback.

The isolated public-runtime comparison with updated code was 10.5% faster for
a generated encode, validation and quality workflow. This excludes codec trials
and is not a promise of the same improvement for every video. GPU encoding and
GPU frame validation are separate stages.

## What does not change

Quality thresholds, full-frame timing and geometry checks, metadata preservation,
corruption detection, size requirements and replacement safety remain unchanged.
The three existing qualified HDR reader scopes remain available with matching
private evidence. Other SDR formats use the existing complete CPU path. This
release does not add H.264 GPU-reader qualification or change FFmpeg dependencies.

## Deployment requirements

Keep the existing media, output and GPU-monitor mounts. To enable this host's
qualified reader, mount the administrator-installed directory
`/var/lib/muxmender-reader-qualification` read-only at
`/opt/muxmender-host-qualification`. Never use writable output as the receipt mount.
See `docs/host-reader-qualification.md`; private receipts are not in public images.

The exact new image passed runtime, generated NVIDIA and host-receipt dispatch
checks. The earlier development-code mount into v60 was integration evidence;
the final check did not mount development application code. Production was not
restarted or resumed. Registry publication and installation remain separate.
