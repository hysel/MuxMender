# MuxMender 20261002-v49

## A simpler media workspace

- Overview, Add videos and Results are separate views. Lifetime savings and
  CPU, GPU encoding use and available RAM stay visible above them.
- Setup highlights choose, configure and review steps. Action values and
  replacement approval are unchanged; nothing starts just by selecting a folder.
- Quick result filters and plain-language reasons make outcomes easier to read.
  Search, technical evidence, result management and reports remain available
  without taking over the screen.
- Light, dark, phone-width layouts, keyboard focus and labelled controls were
  checked. This is not a formal accessibility certification.
- Cancellation has an explicit close button, Escape and backdrop dismissal.
  Empty queues show a message instead of opening an unnecessary confirmation.

## Processing improvements carried forward

Includes adaptive GPU-stage scheduling and the v48-r2 processing corrections:
discard-only audio sample clocks avoid false null-mux timestamp failures while
strict corruption and independent timing checks remain; original full HDR
evidence is checked before encoding and reused afterward. User-selected time
limits, quality thresholds, savings policy and publication safeguards are unchanged.
The early HDR check does not make decoding faster or raise a processing limit.

## Deploy

Image tag: `muxmender-app:20261002-v49`.
The stage script builds a fresh context and runs isolated runtime, process-reaping,
dashboard and generated NVIDIA HEVC/AV1 smoke checks. It does not switch the
installed app, change the production queue or touch source media.

After checks pass, change only the app image. Keep the existing media/output
mounts, GPU assignment, port, UID/GID and GPU-monitor settings. Refresh the
browser after deployment. Saved queue and result history remain on the output
mount; this is not a fresh queue or automatic retry of old failures.

UI regression and browser checks passed with illustrative data. Full-file
hardware performance of the adaptive admission policy remains to be measured.
