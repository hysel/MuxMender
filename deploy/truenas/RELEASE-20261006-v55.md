# MuxMender 20261006-v55

## Smaller copies without changing copied audio

Two full-file NVIDIA conversions passed the unchanged quality, decode, frame
timing, copied-track and metadata checks. The HDR/Dolby Vision + TrueHD test
was 39.20% smaller; the SDR + DTS test was 51.16% smaller. Sources remained
unchanged and the copies were not published.

The shared mux path preserves Matroska timestamp precision for TrueHD. A
strict packet relay handles the qualified copied-DTS clock regression without
resampling or changing presentation timestamps. Chapter checks distinguish
stored chapter ends from ends a reader infers from container duration; genuine
chapter changes still fail. No quality or preservation threshold was relaxed.

## A more compact workspace

The new retro operations-terminal design includes light and dark themes,
compact active rows, current-stage progress, expandable details and a tighter
footer. Keyboard focus, contrast and reduced-motion behavior are retained.
Losing a remote status observer reports stale progress, not a stopped conversion.

## Output presets: qualification limits

Original resolution, 1080p / 8 Mbps, 720p / 4 Mbps and 480p / 1.5 Mbps choices
share one implementation across the app and CLI. Generated progressive SDR
tests passed against NVIDIA H.264, HEVC and AV1 with target-resolution quality
checks and full output bitrate measurement. These are not universal Plex
Direct Play guarantees. Real-media resizing, interlaced resizing, HDR resizing
and HDR-to-SDR rendering are still pending; unqualified transformations retain
the original with a reason. Original-resolution HDR preservation is unchanged.

This package also consolidates the prior adaptive admission, GPU sharing,
validation scheduling, GPU reader and reliability work since the last public
merge. See the individual release notes and qualification limits for those
changes. Preparing the package does not change the installed app or queue.

## Deployment gate

Build and smoke-test the packaged image on TrueNAS before installing it.
Image qualification and deployment are separate from source regression tests.
