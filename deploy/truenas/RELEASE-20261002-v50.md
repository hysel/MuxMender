# MuxMender 20261002-v50

## What changed

- Completed-results and queued/running filters are clearly distinguished.
  Current retries no longer inherit a previous failure's reason or category.
- Resource-setting buttons align with their controls. Queue pause and display
  freeze have distinct labels. Savings explanations use plain language.
- The full HDR source-frame check is shown as inspection, not encoding.
- Include API discovery at `/api` and its documentation. Existing host and
  control-request protections remain; trusted-network access is still required.
- Reuse checksummed metadata for small generated references within a job.
  Reuse complete source PCM evidence in the existing audio fallback for small
  sources, after source and evidence checksums match. Every output is freshly
  checked. Larger sources keep the original decode path.

All earlier adaptive resource, cancellation, validation and cleanup work remains.
Quality, metadata, timing, savings and replacement requirements are unchanged.

## Performance expectations

Audio comparisons improved 17.1% on the generated test. Four-thread SDR frame
reading improved 46.8% versus two threads with identical complete evidence.
The adaptive SDR policy already chooses workers based on headroom: neither
number is an additional guaranteed full-file or HDR conversion improvement.

Faster NVIDIA presets, paired frame readers, compressed evidence and experimental
short-job priority are not enabled as new production defaults.

## Deploy

Image: `muxmender-app:20261002-v50`.
Cancel or pause/drain the current batch and wait for active work to stop before
updating. The stage script builds and checks an isolated image; it does not
switch the installed app or alter its queue, mounts or source files.

After smoke checks pass, change only the image tag in TrueNAS. Keep existing
media/output mounts, GPU assignment, port, UID/GID and monitor settings. Refresh
the browser. Saved results and queue records are retained; inspect queue state
before resuming. No source media is changed by packaging or smoke tests.
